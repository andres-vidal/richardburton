# Publication index list

The **mobile** presentation of the publication index — a stacked list of cards,
one per publication, showing the translation (title and translators) alongside
the original work it renders and its publisher, year, and countries. It is the
read-only counterpart to the [index table](?path=/docs/publications-index-table--docs),
which takes over on wider screens.

## Data source

The list is **state-driven**: it takes no publication props. It reads the
row ids from the publication store (`usePublicationIds`) and each
card resolves its own row (`usePublication`), so the list re-renders as the
store changes. In stories the store is seeded through the shared fixtures:

```tsx
import { seedIndex } from "test/publication-fixtures";

seedIndex(store); // load the sample publications before the story renders
```

`onItemClick(id, event)` is called with the id of the tapped publication, so a
parent can route to (or select) it.

## Drawing entries near the viewport

The list is not virtualised: it holds an `<li>` for every loaded id. An entry
draws its publication once it comes within 800px of the viewport, and keeps it
drawn from then on. Until then the entry is an empty box of about an entry's
height, so the scroll height is close to the final one and the list does not
draw every loaded publication at once.

Because an entry is never emptied again, its height changes only once, usually
before it scrolls into view. Entries above the viewport do not resize while the
list is read. Entries are memoised, so loading another page draws only the new
ones.

<Canvas of={IndexListStories.DrawsAsItIsScrolled} />

An entry under `display: none` never comes into view. A list that a breakpoint
hides therefore draws no publications, and costs one empty `<li>` per loaded
id. The server renders
every entry empty as well, so the first render in the browser matches it.

## States

The list resolves to one of three states from the store alone:

- **Populated** — the sample above: an `<ol>` of cards for every visible id.
- **Empty** — ids loaded and none to show, because the database is empty or
  the search matched nothing; renders `EmptySearchResults`. See the
  [Empty](?path=/story/publications-index-list--empty) story.
- **Loading** — ids not loaded yet (`undefined`); renders a
  [`PublicationIndexListSkeleton`](?path=/docs/publications-index-list-skeleton--docs),
  ten placeholder entries in the shape of the list's entries.
