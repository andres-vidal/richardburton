# Rich text area

A labelled field that edits rich text with Slate. It takes and gives the text
as its value: the list of blocks described in `modules/rich-text`, which is
also the value Slate edits. It supports paragraphs and line breaks, bold and
italic text, bulleted and numbered lists, nested up to three levels, and links.
The [rich text](?path=/docs/components-rich-text--docs) component renders the
same value read-only.

## Props

- `label` — the name of the field, shown over it. It names the text area, a
  multi-line textbox.
- `hint` — optional words under the label that describe the text area.
- `placeholder` — optional text shown in the empty text area.
- `value` — the text's value, or null for none. The field reads it when it
  mounts, and again whenever it changes to a value the field has not passed to
  `onChange`, as when another person edits the same text. Reading it again
  clears the field's undo history. A value the field passed earlier changes
  nothing, even when it comes back after newer ones. Values are compared with
  lodash's `isEqual`, so the order of the keys in their objects does not
  matter.
- `onChange` — receives the edited value each time it changes, or null when
  the text is blank. A change of the selection alone calls nothing.
- `error` — what is wrong with the text. It is shown under the field, describes
  the text area after the hint, and marks the text area invalid.

## Size

The text area is 10rem tall when empty. It grows with its text up to 20rem and
scrolls after that. The placeholder starts where the caret does, and wraps
inside the text area.

## Formatting

The toolbar, named "Formatting", holds Bold, Italic, Bulleted list, Numbered
list and Link. A button that toggles something is pressed (`aria-pressed`) and
outlined in the primary colour while the selection has it. Pressing a button
keeps the focus and the selection in the text.

Ctrl+B and Ctrl+I, or Cmd on a Mac, toggle bold and italic. Shift+Enter breaks
the line within a paragraph or an item, and undo and redo use the usual
shortcuts.

In a list item, Tab and Shift+Tab move the item a level deeper or shallower,
and Enter on an empty item, or Backspace at the start of an item, takes it out
a level and then out of the list.

## Links

The Link button, or Ctrl+K, opens a small dialog under the button. It asks for
the address, which can be a URL, a web address without `https://`, or an email
address, and for the text of a new link when no text is selected. In a link, it
edits the link's address and offers Remove link. Escape closes it without
closing a dialog around the field, and does nothing while a key is being
composed, as with an input method.

A URL or an email address typed into the text becomes a link once a space or a
new line follows it, and one that is pasted becomes a link at once, or links
the selected text. Pasted text is inserted as plain text, one block per line,
with each URL and email address in it linked.

## A value that comes back late

A parent may pass back each value the field gave it some time later, after
more has been typed. The field ignores those values, so the text and the caret
stay where the typing left them.
