# Publication upload

An outlined "Upload .csv" button in the import workspace's footer. It opens a
hidden file input, and the rows of the chosen file are added after the rows
already in the import document.

The server parses and validates the file, and `upload()` appends its rows with
their validation results through `append` in the publication store. The rows
are added as one edit of the person who uploaded them, so their Undo takes the
whole upload out again. Rows already in the document, including other people's,
are kept. After a failed upload, or after the upload finishes, the input is
reset, so the same file can be chosen again.
