# Admin menu

The admin hub: a card per admin tool. It's linked from the home footer so the
admin actions live on one page instead of cluttering the footer. Each card is a
link to its route with a title and a one-line description.

## Data source

Takes no props. The tools are a static `ACTIONS` list in the component — add a
new admin tool by adding an entry (`href`, `title`, `description`, `role`) and
it slots into the responsive grid. Currently:

- **Add publications** → `/admin/publications/new`
- **Backfill references** → `/admin/publications/references`
- **History** → `/admin/publications/history`
- **Deleted publications** → `/admin/publications/deleted`
- **Access** → `/admin/users`

## Who sees what

Each entry names the least role that may reach it — the same role its route
asks for — and the menu shows the ones the reader holds. A card that leads
somewhere the reader would be turned away from is worse than no card.
