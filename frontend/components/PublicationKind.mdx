# Publication kind

One line that says a publication is a retranslation or a reissue. It shows a
badge that names the kind, an [info hint](?path=/docs/components-info-hint--docs)
that defines the kinds, and a sentence that links to the earlier publication
this one follows. It renders nothing for a first translation.

The server decides the kind of a publication and the publication it follows,
and `GET /publications/:id` returns both with the publication. Within a work,
the earliest publication of the earliest translation is the first translation.
The first publication of any later translation of the work is a retranslation,
and any later publication of a translation is a reissue. The hint shows the
same definitions as the insights charts.

## Props

- `kind` — `"first_translation"`, `"retranslation"` or `"reissue"`.
- `follows` — the publication this one follows, with its id, title, year and
  translators, or `null` for a first translation.
