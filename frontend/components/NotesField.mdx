# Notes field

The field that edits the notes of one row of the enclosing publication store,
in Portuguese and in English. It is a
[notes editor](?path=/docs/publications-notes-editor--docs), with a tab for
each language, that shows the row's notes in each language, and the error the
row has with each under its text.

<Description of={NotesFieldStories.WithNotes} />
<Canvas of={NotesFieldStories.WithNotes} />

## Props

- `id` — the row whose notes the field edits. The field reads the row's notes
  with `usePublicationNotes` and their errors with `usePublicationFieldError`,
  and writes edits to the row with `setNotes`, in the language of the tab they
  were made in. The notes are saved with the rest of the row, so the field has
  no save of its own.

## Writing to the row

The field does not write each keystroke to the row. It writes an edit once the
typing pauses for `SETTLE` milliseconds (500, from
`modules/publication/checks`), so a burst of typing is one write of the last
value. The row is in a document that other people may share, so each write is
a change they receive.

<Description of={NotesFieldStories.WrittenAfterAPause} />
<Canvas of={NotesFieldStories.WrittenAfterAPause} />

Each language waits for its own pause, so switching tabs while a write waits
does not drop it.

<Description of={NotesFieldStories.WrittenInBothLanguages} />
<Canvas of={NotesFieldStories.WrittenInBothLanguages} />

When the field loses the focus, it writes the waiting edits at once. Pressing
a button such as Save takes the focus, so the row holds what was typed before
the button's own handler runs.

<Description of={NotesFieldStories.WrittenOnBlur} />
<Canvas of={NotesFieldStories.WrittenOnBlur} />

Escape pressed in the field also writes the waiting edits at once, before the
handlers around the field receive the key press. A dialog that checks for an
unsaved edit before it closes on Escape then finds the notes in the row.

<Description of={NotesFieldStories.WrittenOnEscape} />
<Canvas of={NotesFieldStories.WrittenOnEscape} />

When the field unmounts, as when the dialog it is in closes, it also writes the
waiting edits at once. It writes them in a layout effect's cleanup, which React
runs before the `useEffect` cleanups of the components around the field, so the
writes land before any of them reads or resets the row.

<Description of={NotesFieldStories.WrittenOnClose} />
<Canvas of={NotesFieldStories.WrittenOnClose} />

Until a write lands, the row's notes are behind the text in the field. The rich
text area ignores a value it passed to `onChange` earlier when that value comes
back late, so the text typed after it stays in the field.

## Drafts

A draft made with the editor's draft button is written to the row at once, in
place of any edit of its language that is waiting.
