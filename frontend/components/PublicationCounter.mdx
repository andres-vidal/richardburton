# Publication counter

A small button that reports how many rows the import workspace holds: a sparkle
icon next to the count, with a tooltip like "3 new publications". It sits in the
workspace's footer as a total of the rows that would be submitted.

## Data source

The counter is **state-driven**: it takes no props. It reads the row count
from the publication store via `usePublicationCount`, so it updates on its own
as rows are loaded, added, or removed. In
stories the store is seeded through the shared fixtures:

```tsx
import { seed } from "test/publication-fixtures";

seed(store); // load the sample publications before the story renders
```

## States

- **Populated** — the sample above: with the 3 sample rows the button reads "3".
  The label pluralizes, so a single row tooltips "1 new publication".
- **Empty** — when the count is 0 the counter renders nothing at all, keeping the
  toolbar clean until there is something to count.
