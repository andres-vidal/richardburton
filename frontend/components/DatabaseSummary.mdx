# Database summary

The line that heads the database: how many publications it holds or a search
found, and links to the two ways of reading them. The list shows the
publications themselves, and the insights count what they hold.

<Canvas of={DatabaseSummaryStories.OverTheList} />

## Props

- `summary` — the count in words, written by the page, since the index and the
  insights count in the same words but from different places.
- `view` — the view this summary heads, `list` or `insights`. Its link is marked
  as the current page.

<Canvas of={DatabaseSummaryStories.OverTheInsights} />

## Keeping the search

Both links carry the `search` in the address. Changing views goes on reading
the same publications, so a search for one author opens the insights into that
author, and back.

<Canvas of={DatabaseSummaryStories.WhileSearching} />

## Accessibility

- The links are a `nav` named "Ways of reading the database", so the pair is a
  landmark of its own rather than two stray links.
- The current view carries `aria-current="page"`, which is also what styles it.
