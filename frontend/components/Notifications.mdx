# Notifications

Where messages live and how long they last: a stack pinned near the top of the
page, capped, with confirmations timing out and failures waiting. The cards
themselves are [`Notification`](?path=/docs/components-notification--docs) —
this component owns only placement, stacking and lifetime.

Mount `<Notifications />` once per page. Any code can then raise a notification
with `notify`, including code outside React, since it writes to the app store.
A notification names its text by keys in the message catalogue, with the
`values` its messages take, and `Notifications` writes the text in the page's
language. A key with no message is shown as its last part.

```ts
notify({
  level: "warning",
  message: "link.failed",
  detail: "link.failedDetail",
  values: { url: "https://example.com/publications/7" },
});
```

## Lifetime

Confirmations (`success`, `info`) clear themselves after four seconds.
Failures (`warning`, `error`) stay until they are dismissed, because they
usually need acting on. `isFailure` in `Notification` decides which levels are
failures, for the card's aria role and for what times out alike.

## Stacking

Up to five show at once. Beyond that, four show and the rest are summarised as a
count. Moving to another page clears them, since they are about the page that
raised them.
