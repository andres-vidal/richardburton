# Workspace sources cell

The cell at the end of a row in the import workspace. Sources are a list, not
one value, so they are edited outside the attribute grid: an outlined `Button`
shows the source count and opens the sources editor in a dialog.

## Props

`rowId` — the workspace row the cell belongs to. It reads that row's sources
from the store (`usePublicationSources`) and writes edits to the same row
(`setSources`). The bulk insert saves the sources with the rest of the row, so
the cell has no save of its own.

`invalid` / `selected` / `focused` — optional row-state flags (default `false`)
that drive the cell's background so it shares the row's hover / error / selected
highlight, just like the attribute cells. The workspace supplies them for
committed rows and omits them for the plain draft row.

The button label reflects the count: "Sources" when empty (an invitation to add),
"N sources" once there are some. Clicking it opens a modal with the shared
`SourcesEditor`; the click is stopped from bubbling so it doesn't also select
the row.

## States

- **Empty** — no sources yet; the button reads "Sources", labelled "Add
  sources".
- **With sources** — the button reads "N sources", labelled "Edit sources
  (N)".

The stories wrap the cell in a `role="row"` inside a `role="table"`, since a
cell is only valid ARIA inside a row.

## An error

When validation finds something wrong with the sources, such as a file whose
sources in Portuguese and in English could not be paired, the button's tooltip
gives the error, and the editor shows it under the list.

## The look-alike button

When the row resembles something, a second button follows the sources button.
It shows a warning icon and the label "Look-alike". Pressing it opens the
resemblance review on this row, which shows the records in full, with a link to
each stored record.

<Canvas of={WorkspaceSourcesCellStories.LooksLikeAStoredRecord} />

The button's accessible name and tooltip say what the row resembles. They name
each stored record by title and year, and give the number of other rows of the
same import that the row resembles.

- **Resembles a stored record** — "Resembles Dom Casmurro (1953)."
- **Resembles other rows of the import** — "Resembles 2 other rows of this
  import."
- **Resembles nothing** — the button is absent.

The button is at the end of the row, not in the leading cell, because the
leading cell is the row's selection handle and a button there would take clicks
meant to select the row. The warning icon in the leading cell marks the row, and
this button is the control. The button also stops its click from reaching the
row, so pressing it does not select the row.
