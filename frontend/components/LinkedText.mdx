# Linked text

Renders a text with each bare URL in it as a link that opens in a new tab, and
with the words a search matched highlighted. A publication's sources render
through it, so a source that cites a web page leads to that page.

<Description of={LinkedTextStories.WithUrl} />

<Canvas of={LinkedTextStories.WithUrl} />

## Props

- `children` — the text, as a plain string. It may carry the `[[ ]]` markers
  of a search excerpt, which render as
  [`Highlight`](?path=/docs/components-highlight--docs) renders them.

## What counts as a URL

A bare URL is a word that starts with `http://`, `https://` or `www.`, or an
email address. These are the words that notes link when they are typed or
imported (see `bareUrl` in `modules/rich-text.ts`). Punctuation that ends the
word, such as a comma or the full stop that ends a sentence, stays outside the
link.
