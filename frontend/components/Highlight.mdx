# Highlight

Renders the highlighting the index put on an excerpt, so a reader can see what
the search matched.

<Canvas of={HighlightStories.Matched} />

## Props

- `children` — the excerpt to render, as a plain string. The component returns it
  as a mix of plain text and `<mark>` elements.
- `className` — the classes applied to each `<mark>`. Defaults to the amber
  highlight the index uses.

## How it works

For every field it searched, the index returns the text that matched, with the
matched words wrapped in `[[ ]]` (see the backend's
`RichardBurton.Publication.Index.Excerpt`). This component splits on those
markers and wraps every other piece in a `<mark>`. It makes no decision about
what matched; it only renders what the database already decided.

Whether two spellings count as the same word, where one word ends, and which
field an operator applied to are all decided by the search configuration, which
only the database knows, so the highlighting cannot drift from the search. `title:night`
highlights the title and nothing else because the index built an excerpt for the
title alone.

<Canvas of={HighlightStories.Accented} />

Accents are preserved. The index strips them when deciding whether something
matched, but the excerpt it returns is the text as actually stored, so a search
for `angustia` highlights `Angústia` without the accent disappearing from what is
displayed.

An excerpt can contain any number of markers, and all of them are rendered.

<Canvas of={HighlightStories.ManyMatches} />

## Outside a search

A field the search did not match has no excerpt, so the caller passes the stored
value instead (see `Publication.markedValue`). That value contains no `[[ ]]`, so
it renders unchanged. The same goes for any text shown outside a search, such as
a publication's own page opened without a query.

<Canvas of={HighlightStories.Unmatched} />

## Restyling the mark

`className` replaces the classes of every mark, for text that needs a
different highlight, such as a line set quieter than the text around it.
