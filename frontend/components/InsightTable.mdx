# Insight table

A table of the counts a chart draws. A chart that hides its drawing from
assistive technology renders this table beside it, visually hidden, so a screen
reader reads the same counts as rows and columns. With `shown`, the table is on
screen, and can stand in place of the chart.

The table is hidden with `sr-only` unless `shown` is set, so the canvas below is
blank. Its play test reads the table by its rows.

<Canvas of={InsightTableStories.Counts} />

## Props

- `title` — the caption, which is the title of the chart. It is also the
  table's accessible name.
- `heading` — the heading of the first column, such as "Year" or "Decade".
- `series` — the name of each series, one column each. A table with one series
  has no series columns, only the total.
- `rows` — one row for each entry, with its `label`, an optional `detail`, and
  its `counts` in the order of `series`. The last column is the sum of its
  counts.
- `shown` — whether the table is on screen.
