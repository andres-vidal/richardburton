# Anchor

A text link whose underline grows from the centre on hover. It sets no colour
of its own, since the underline is `bg-current`, so it takes the colour of the
text around it.

<Description of={AnchorStories.Default} />
<Canvas of={AnchorStories.Default} />

## Props

- `href` — where it goes. One starting with `http` renders a plain `<a>`. Any
  other goes through the localized `Link`, which adds the current locale to the
  path.
- `query` — a query string appended to `href`. A link with only a `query` stays
  on the current page, so it goes through `next/link` and keeps the page's
  locale.
- `onClick` — makes it a `<button>` instead.

## An action among links

Given an `onClick`, it renders a `<button>` with the same look, so an action can
sit in a row of links and look like one of them. Query it by `button`, not
`link`.
