# Copy link

An icon button that copies a link to the clipboard. It takes a path and copies
it as an absolute URL, made against the current origin, so the link works when
it is sent to someone else. It suits a place where the address bar does not show
the address to share, such as a record opened in a modal over another page.

It is drawn as a bare icon, to sit beside a heading. Its accessible name and a
tooltip carry the label "Copy link", since it has no visible text.

## Props

- `href` — the path to copy.

## Feedback

After a copy, the icon turns green and its name and tooltip say **Copied** for
two seconds, and a notification shows the URL that was copied.
