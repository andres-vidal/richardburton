# Confirmation modal

A dialog that asks for confirmation before a destructive action. It shows the
`title` as its heading, says what is about to happen in the `message`, and waits
for a choice. The confirm button uses the danger variant. Cancelling with the
button, a press on the overlay or <kbd>Esc</kbd> changes nothing.

It is a [Modal](?path=/docs/components-modal--docs) with the `title` as its
`heading`, so the dialog's accessible name is the `title`.

## Props

- `isOpen` — whether the dialog is shown. The caller owns this state, usually
  through `useModal()`.
- `title` — the heading, which also names the dialog.
- `message` — what is about to happen and what it affects.
- `children` — more detail, shown below the message.
- `confirmLabel` — the label of the confirm button, naming the action, such as
  "Delete".
- `loading` — shows the confirm button as loading while the action is in
  flight.
- `onConfirm` and `onCancel` — called on the reader's choice.

## States

Anything passed as `children` is shown below the message, for detail that does
not fit in a sentence, such as a list of the records the action affects.
