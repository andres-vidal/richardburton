# Text array data input

The multi-value cell editor for free-text lists such as `authors`,
`originalAuthors`, and `publishers`. It is the concrete editor that
[Data input](?path=/docs/publications-data-input--docs) dispatches to for
`array` columns, built on a `Multicombobox`.

## Data flow

The stored `value` is the list of values themselves. Each renders as a
removable pill, and the selection goes back through `onChange` as a list.

A comma ends a value, so a name that contains one — `"Cassel, McBride & Co."` —
is written in quotes, the same way the CSV says it. While a quote is open the
comma is just a character, and the quotes come off when the value commits.

Typing suggests the names that `LOOKUP[lookup]` finds, where `lookup` is
`"authors"` or `"publishers"`. The `Multicombobox` calls the search through
`useLookup`, once typing pauses. In Storybook the name searches are stubbed to
find nothing.
