# Document status

Shows whether the changes made here have reached the server, and whether other
people's changes are arriving. It sits in the workspace header, next to
`DocumentPresence`.

<Canvas of={DocumentStatusStories.Saved} />

## Saving and live status

Saving and the live connection can fail separately, and only a failed save can
lose work. The component still shows a single label, so a reader can tell at a
glance whether anything is wrong.

When both fail, the label is **Not saved**.

- **Saved** — everything typed here has reached the server.
- **Saving** — some changes made here have not reached the server yet.
- **Reconnecting** — the live connection is being opened, or opened again after
  it dropped. Changes made in the meantime are kept and sent when it is back.
- **Not live** — changes are saving, but other people's changes are not
  arriving.
- **Not saved** — changes made here are on this computer but have not reached
  the server. The failed request is retried after a delay that doubles each
  time, up to 30 seconds.

<Canvas of={DocumentStatusStories.NotSaved} />

## Props

None. It reads the document's state from the `LiveProvider` context that
`DocumentProvider` sets up. Outside that context it renders nothing, for example
in the edit form for a single saved publication, which is not a shared document.
