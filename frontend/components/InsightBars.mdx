# Insight bars

A titled list of counts. Each item has a bar, and the bar's length is the
item's count as a fraction of the largest count in the list.

<Canvas of={InsightBarsStories.Names} />

## Props

- `title` — the heading of the list. It is also the accessible name of the
  section around the list.
- `bars` — the items, in the order they are listed. Each has a `key`, a
  `label`, an optional `detail` shown after the label, the `count` that sets
  the bar's length, and a `value`, which is the count as text.

The caller formats each `value`, because the unit differs between lists. Most
lists count publications, and the list of works translated more than once
counts translations.

<Canvas of={InsightBarsStories.WithDetails} />

## Items with a count of 0

An item with a count of 0 is listed with an empty bar. It is not left out, so a
decade with no publications still appears in the list of decades.

<Canvas of={InsightBarsStories.WithNothingCounted} />

## Accessibility

- The list is an `ol` inside a `section` labelled by the title.
- The bars have `aria-hidden`. Assistive technology reads the label and the
  value instead.
