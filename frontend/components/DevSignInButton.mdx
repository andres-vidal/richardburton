# Dev sign-in

A button per role that signs in as that role without the Google handshake, for
development. It takes no props.

<Description of={DevSignInButtonStories.Default} />
<Canvas of={DevSignInButtonStories.Default} />

## What a button does

Each button loads the `/api/auth/dev` route handler as a whole page, so the
browser stores the session cookie that the handler's redirect sets. The handler
starts a session for the role's own account, so signing in as one role does not
change the account of another.

The handler then makes the same decision the OAuth callback makes: it sends each
role where a real sign-in would, and a role the sign-in gate turns back gets no
session. A **Reader** therefore lands on the pending page rather than the admin
pages.

## Only in development

The route handler answers 404 when `NODE_ENV` is not `development`, and the
backend endpoint behind it is compiled only into the development, test and
end-to-end builds.
