# Publication duplicate

A secondary button in the import workspace's footer, shown while rows are
selected. It copies the selected rows, each copy right after its row, and
clears the selection. Its label counts the selected rows ("Duplicate 2").

The copies are written to the import document as one edit of the person who
made them, so one undo removes them all. The document's checks validate the
new rows, as they do after any edit.

## Props

None. The button reads the selection from `modules/selection`, and copies the
rows with `duplicate` from the publication store.
