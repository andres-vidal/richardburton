# Publication download

The button that exports the current publication view as a CSV. It mirrors the
active search and column selection, so what you download matches what you see in
the index.

## Data source

The button is **state-driven**: it takes no props. It reads the row count
(`usePublicationCount`) to decide whether it is enabled, and the visible
attributes (`useVisibleAttributes`) to build the export's `select` — omitted
when every column is shown, otherwise the snake-cased visible columns. It also
pulls the current `search` from the router query so the export respects the
active filter. Clicking issues a GET for the file and saves it through a link
that is not attached to the page, under the name the server gave in
`content-disposition`, or `publications.csv` when that header is missing or
unreadable, since a file that arrived is not a failed download. Only a request
that failed raises a notification. The file is released from memory a minute
after it is saved. In stories the store is seeded through the shared
fixtures:

```tsx
import { seed } from "test/publication-fixtures";

seed(store); // load the sample publications before the story renders
```

## States

- **Enabled** — the default: there are visible publications, so the button is
  clickable and a click would download them.
- **Empty** — nothing to export (`seed([])`), so the button is disabled. See
  the [Empty](?path=/story/publications-download--empty) story.
