# Button link

A link that looks like a [button](?path=/docs/components-button--docs), for an
action that goes to another page rather than doing something on this one. It
takes the button's `variant`, `size` and `width`, and renders the app's
localized `Link`, so the address keeps the current language.

The two share one class list, `BUTTON_CLASS_NAME` from `Button`, so a link and a
button side by side look alike.
