# Notes editor

Edits a publication's notes as rich text, with Slate. The notes are
stored as Markdown, and the editor reads and writes that Markdown through
`parse` and `serialize` in `modules/notes`. It supports paragraphs and line
breaks, bold and italic text, bulleted and numbered lists, nested up to three
levels, and links.

## Props

- `value` — the notes in Markdown, or null for none. The editor reads it when
  it mounts, and again whenever it changes to Markdown other than what the
  editor last passed to `onChange`, as when another person edits the same
  notes. Reading it again clears the editor's undo history.
- `onChange` — receives the Markdown the text is written as, each time that
  Markdown changes. An empty editor passes an empty string. A change of the
  selection alone calls nothing.
- `error` — what is wrong with the notes, such as the server's
  `publicationError.too_long`. It is shown under the editor, describes the text
  area and marks it invalid.

## Formatting

The toolbar holds Bold, Italic, Bulleted list, Numbered list and Link. A
button that toggles something is pressed (`aria-pressed`) and outlined in the
primary colour while the selection has it. Pressing a button keeps the focus
and the selection in the text.

Ctrl+B and Ctrl+I, or Cmd on a Mac, toggle bold and italic. Shift+Enter breaks
the line within a paragraph or an item, and undo and redo use the usual
shortcuts.

In a list item, Tab and Shift+Tab move the item a level deeper or shallower,
and Enter on an empty item, or Backspace at the start of an item, takes it out
a level and then out of the list.

## Links

The Link button, or Ctrl+K, opens a small dialog under the button. It asks for
the address, which can be a URL, a web address without `https://`, or an email
address, and for the text of a new link when no text is selected. In a link, it
edits the link's address and offers Remove link. Escape closes it without
closing a dialog around the editor.
