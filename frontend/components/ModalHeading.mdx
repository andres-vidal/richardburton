# Modal heading

Renders what a dialog is called as an `h1` in a bar pinned to the top of the
dialog while its content scrolls, so the heading stays in view in a long dialog.

<Canvas of={ModalHeadingStories.Default} />

## Props

- `heading` — what the dialog is called. Rendered as its `h1`.
- `subheading` — a line under it, pinned with it. Usually how much the dialog
  holds.
- `aside` — set against the heading at the end of the bar, for a dialog that is
  one of a queue.
- `id` — the `id` of the `h1`, for a dialog named by its heading.

## Where it can sit

It spans the padding around it with negative margins, so it has to be the first
child of an element with `p-8`. Outside one it hangs over the edges.

The background is translucent and blurred, so the content that scrolls under it
stays faintly visible.

A heading longer than the bar is cut short with an ellipsis rather than wrapped,
so the bar keeps its height and the content under it does not move.
