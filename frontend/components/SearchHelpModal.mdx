# Search help

Documents the search syntax. The input tolerates missing accents and
misspellings, narrows on every word, and accepts field operators, none of which
is discoverable from the input itself.

<Canvas of={SearchHelpStories.Open} />

## What it covers

- **Spelling and accents** — accents may be omitted or included, minor
  misspellings are tolerated, and an incomplete word matches by prefix. Listed
  first because they apply to every search, operators or not.
- **Searching a single field** — `title:`, `author:` (the author of the
  original work), `translator:`, `publisher:`, `country:`, `original:` and
  `source:`, plus `year:` for a single year or a range.
- **Refining a search** — quotation marks for a phrase in the order given,
  parentheses for several words of one field in any order, a leading minus to
  exclude, and a repeated operator to require both values.
- **Broadening a search** — `:or`, the only operator that widens rather than
  narrows.

## In Portuguese

## How it opens

The modal is open while the URL has a `search-help` query parameter, so a link
can open it. `SEARCH_HELP_MODAL_KEY` is the name of that parameter. Opening it
keeps the rest of the query, so the search being refined stays behind it.
Without the parameter, nothing is rendered.

<Canvas of={SearchHelpStories.Closed} />

## Scope

Each row gives a query and what it matches. Nothing here describes how the
search works, such as indexes, ranking or tsquery syntax. The copy has to change
whenever an operator does.
