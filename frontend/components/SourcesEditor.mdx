# Sources editor

The editor for a publication's **sources** — free-text provenance entries
that record how the record's data was collected, so a reader can verify it. It
lives in the publication
[edit form](?path=/docs/publications-publication-detail--docs), below the other
fields, and in the dialogs of the import document's sources cell and of the
sources backfill.

## Data flow

Unlike the array cell editors (authors, publishers), a source is not a
comma-joined string but a genuine ordered list: provenance is free text that may
itself contain commas. Each source has a text in Portuguese and a text in
English, either of which may be missing. The `value` is therefore a list of
`{ pt, en }` sources, and every action — add, edit, remove, reorder — produces a
**new list** through `onChange`. The component keeps no sources of its own;
the parent owns the list (in the app, the publication's row in the store).

Reordering is a plain swap driven by the ↑/↓ controls (bounded at the ends,
no drag). Sources with no text in either language are allowed while editing and
dropped server-side on save, so an empty row never blocks a submit.

## Props

- `value` — the sources, in order, each with its text in each language.
- `onChange` — receives the new list after each action.
- `error` — an error with the sources, shown under the list.

## Two languages

The list is shown in a tab for each language (see
[language tabs](?path=/docs/components-language-tabs--docs)), and the tab of
the reader's language is selected at first. Both tabs list the same sources in
the same order: adding, removing or moving a source does so in both
languages, and typing in a tab sets the source's text in that tab's language.
A source with no text in the tab's language shows its text in the other
language as its placeholder.

## Drafting the other language

Beside the tabs, a [draft button](?path=/docs/components-draft-button--docs)
drafts, in a browser that can translate, the text of each source that has none
in the selected tab's language from its text in the other language. Sources
that already have text in that language are left alone. A source cites works
by their titles, which must stay as written, and the browser's translation
model cannot be told to keep them, so the tab asks to check the titles after a
draft.
