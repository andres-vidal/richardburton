# Sources editor

The editor for a publication's **sources** — free-text provenance entries
that record how the record's data was collected, so a reader can verify it. It
lives in the publication
[edit form](?path=/docs/publications-publication-detail--docs), below the other
fields, and in the dialogs of the import document's sources cell and of the
sources backfill.

## Data flow

Unlike the array cell editors (authors, publishers), a source is not a
comma-joined string but a genuine ordered list: provenance is free text that may
itself contain commas. A publication has one such list in Portuguese and
another in English. The `value` holds both lists, and every action — add, edit,
remove, reorder — passes its language and that language's **new list** to
`onChange`. The component keeps no sources of its own; the parent owns the
lists (in the app, the publication's row in the store).

Reordering is a plain swap driven by the ↑/↓ controls (bounded at the ends,
no drag). Blank sources are allowed while editing and dropped server-side on
save, so an empty row never blocks a submit.

## Props

- `value` — the sources of each language, `{ pt, en }`, each a list in order.
- `onChange` — receives the language and its new list after each action.
- `errors` — what is wrong with the list of each language, shown under that
  list, with its tab shown in red.

## Two languages

Each language's list is shown in a tab of its own (see
[language tabs](?path=/docs/components-language-tabs--docs)), and the tab of
the reader's language is selected at first. The two lists are independent: a
source in one list has no counterpart in the other, and adding, removing,
moving or editing a source in one tab leaves the other tab's list as it is.

## Drafting the other language

Beside the tabs, a [draft button](?path=/docs/components-draft-button--docs)
drafts, in a browser that can translate, the selected tab's list from the other
language's list, translating each source that is not blank. A source cites
works by their titles, which must stay as written, and the browser's
translation model cannot be told to keep them, so the tab asks to check the
titles after a draft.
