# Role menu

A button showing a role's name that opens a menu of every role, least
privileged first. It is the app's own menu, `MenuProvider`, rather than the
platform's `<select>`, so it looks and behaves like the app's other menus.

<Canvas of={RoleMenuStories.Default} />

## Props

- `value` — the role shown.
- `label` — the accessible name, which says whose role it is or what it is for.
- `disabled` — disables the button.
- `onChange` — called with a role other than `value` when one is picked.

## How it is built

`MenuProvider` supplies the listbox, keyboard navigation and dismissal, but not
what opens it, so the button keeps `isOpen` and toggles it on click, as
`Select` does.

A button paired with a listbox takes the **`combobox`** role, so query it by
`combobox`, not `button`.

Each option has the role as its id and the role's name as its label, so
`onChange` gets the stored value, such as `admin`, while the reader sees
"Administrator".
