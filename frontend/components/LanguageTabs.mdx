# Language tabs

A tab for each language a publication's notes and sources are written in,
Português and English, and a panel for each. Only the selected panel shows.
The [notes editor](?path=/docs/publications-notes-editor--docs) and the
[sources editor](?path=/docs/publications-sources-editor--docs) put the text of
each language in its panel.

## Props

- `label` — the accessible name of the tab list, such as "Language of the
  notes".
- `selected` and `onSelect` — the selected language, and the function that
  receives a language when its tab is chosen. The caller keeps the selection.
- `invalid` — the languages whose panel holds an error. Their tab is shown in
  red.
- `actions` — content shown at the end of the row of tabs, such as a button
  that acts on the selected panel.
- `children` — a function that renders the content of a language's panel.
  Both panels stay mounted, so a field in the hidden panel keeps its state.

## Keyboard

The tabs follow the tab pattern of the WAI-ARIA Authoring Practices. Only the
selected tab is in the tab order, and the arrow keys, Home and End select a tab
and move the focus to it.
