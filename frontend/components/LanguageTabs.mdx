# Language tabs

A tab for each language a publication's notes and sources are written in,
Português and English, and a panel for each. Where there is little room, only
the selected panel shows. In a container of 48rem or wider, the tabs are
hidden and the two panels show side by side, so the text in one language can
be read while the other is written. The [notes editor](?path=/docs/publications-notes-editor--docs) and the
[sources editor](?path=/docs/publications-sources-editor--docs) put the text of
each language in its panel.

## Props

- `label` — the accessible name of the tab list, such as "Language of the
  notes".
- `selected` and `onSelect` — the selected language, and the function that
  receives a language when its tab is chosen. The caller keeps the selection.
- `errors` — the error of each language whose panel holds one. Their tab is
  shown in red, whether or not it is selected.
- `empty` — the languages nothing is written in. Their tab says so, in a mark
  after its name that is also the tab's description.
- `actions` — a function that renders what acts on a language's panel, such
  as a button that fills it. It is shown at the top of that panel.
- `children` — a function that renders the content of a language's panel.
  Both panels stay mounted, so a field in a panel that does not show keeps
  its state.

## Keyboard

The tabs follow the tab pattern of the WAI-ARIA Authoring Practices. Only the
selected tab is in the tab order, and the arrow keys, Home and End select a tab
and move the focus to it.
