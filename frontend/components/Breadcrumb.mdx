# Breadcrumb

Renders the path from the home page to the current page as a trail of crumbs.
The crumbs before the last are links back up the path, and the last one names
the current page as plain text.

## Props

A single `items` prop: an ordered list of crumbs from the root down to the current
page. Each crumb is `{ label, href? }`. Give a crumb an `href` to render it as a
link; omit it on the **last** crumb so the current page reads as plain text.

```tsx
<Breadcrumb
  items={[
    { label: "Home", href: "/" },
    { label: "Admin", href: "/admin" },
    { label: "Backfill sources" }, // current page — no href
  ]}
/>
```

## Accessibility

- It is a `<nav>` named "Breadcrumb" around an ordered list, so assistive
  technology announces it as a navigation landmark with its crumbs in order.
- The current page carries `aria-current="page"` and is not a link.
- The `/` separators are decorative (`aria-hidden`), so they are not read out.
