# Notes

A publication's notes, rendered from the Markdown they are stored as. It
renders paragraphs, line breaks, bold and italic text, bulleted and numbered
lists, nested lists included, and links. Every link opens in a new tab with
`rel="noopener noreferrer"`.

The Markdown is read with `parse` and laid out with `toTree` from
`modules/notes`, the same conversion the notes editor writes with, so the
page shows what the editor showed. The component builds React elements from
that tree and sets no HTML of its own.

## Props

- `markdown` — the notes in Markdown. Empty, null or missing notes render
  nothing.
- `size` — `base`, the default, for the publication's page, or `small` for a
  denser place such as the history.

## Markdown that notes do not support

Notes support a subset of Markdown. The rest keeps its text: a heading is a
paragraph, code and raw HTML are text, an image is its alternative text, and a
link to anything but an `http`, `https` or `mailto` address is its label.
