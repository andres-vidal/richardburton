    RichardBurton.RichText (richard_burton v0.1.0)

    An Ecto type for rich text stored in a jsonb column, and functions that measure rich text and convert it to and from plain text.

    These terms describe rich text. The keys of every node are strings.

    • value — a non-empty list of blocks, in reading order, or nil when there is no text.
    • block — a paragraph or a list item. A paragraph is %{"type" => "paragraph", "children" => inlines}. A list item is %{"type" => "list-item", "list" => kind, "depth" => depth, "children" => inlines}.
    • kind — the kind of list an item belongs to, "bulleted" or "numbered".
    • depth — how deep a list item is, from 0 for an item of a top-level list to 2. Lists are not nested in the value: a nested list is a run of items one level deeper than the item before them.
    • inline — a run or a link.
    • run — a run of text, %{"text" => text}, with "bold" and "italic" as optional booleans. A "\n" in the text is a line break.
    • link — %{"type" => "link", "url" => url, "children" => runs}. The URL starts with http://, https:// or mailto:, in any case, has something after that, and holds no whitespace.

    Every list of children holds at least one node, and a node holds no keys other than the ones listed for it. A value or a block is blank when the text of its runs, the runs of its links included, is empty or only whitespace.

    A value is normalized when none of its lists skips a level. The first list item that is not blank after the start of the value, or after a block that is not a list item, blank or not, is at depth 0. Every other list item that is not blank is at most one level deeper than the last list item before it that is not blank. A blank list item may be at any depth.

    Casting a value checks the shape these terms describe, and returns nil for a blank value or an empty list. Any other value is returned normalized. Casting goes through the list items that are not blank in order, and lowers each one that is too deep to the deepest depth a normalized value allows. Blank blocks are kept as they are. A value of any other shape, such as one whose nodes have atom keys, or one with more than 10,000 nodes, fails to cast with the validation :malformed.

    A bare URL is a word of plain text that from_plain_text/1 reads as a link: a web address or an email address, as that function describes.

    from_plain_text(text)

    @spec from_plain_text(String.t() | nil) :: t() | nil

    Returns the rich text that plain text holds, or nil when text is nil or blank.

    Line endings are read as "\n", whether written as "\r\n", "\r" or "\n". One or more blank lines start a new paragraph, and a single line break inside a paragraph is a line break in its text. Each paragraph is trimmed, and the whitespace at the end of each line is dropped.

    Each bare URL in the text becomes a link. Words are separated by whitespace, line breaks included. A word is a bare URL when, without the punctuation at its end, any of .,;:!?)]'", it starts with http://, https:// or www., in any case, followed by a character other than a full stop, or it is an email address. An email address is text, @, and a domain with a full stop inside it, none of which holds whitespace, @, <, >, parentheses or square brackets.

    The link's text is the bare URL as written, and the punctuation after it stays in the text that follows the link. The link goes to:

    • the bare URL itself, when it starts with http://, https:// or mailto:, in any case.
    • the bare URL after mailto:, when it is any other email address.
    • the bare URL after https://, when it is a web address: names of ASCII letters, digits, _ and - joined by full stops, followed by nothing, or by a path, query or fragment that starts with /, ? or #.

    A bare URL that is none of these stays text. No other formatting is read: every block is a paragraph, and the text around the links is in runs without marks.

    Examples

    iex> RichardBurton.RichText.from_plain_text("First edition,\r\nin English.\n\n\nBound in cloth. ")
[
  %{"type" => "paragraph", "children" => [%{"text" => "First edition,\nin English."}]},
  %{"type" => "paragraph", "children" => [%{"text" => "Bound in cloth."}]}
]

iex> RichardBurton.RichText.from_plain_text("See www.example.com/catalogue.")
[
  %{"type" => "paragraph", "children" => [
    %{"text" => "See "},
    %{"type" => "link", "url" => "https://www.example.com/catalogue",
      "children" => [%{"text" => "www.example.com/catalogue"}]},
    %{"text" => "."}
  ]}
]

iex> RichardBurton.RichText.from_plain_text(" \n ")
nil

    to_plain_text(value)

    @spec to_plain_text(t() | nil) :: String.t()

    Returns value as plain text, or an empty string for nil.

    The blocks are written in order. Consecutive list items are on consecutive lines, and every other pair of blocks is separated by a blank line. Blank blocks are left out. A line break in a block starts a new line, and the whitespace at the ends of each line is dropped, except the indentation of a line after a line break.

    A list item is written after - when it is bulleted, and after N. when it is numbered, indented by two spaces for each level of its depth. The lines after a line break in a list item are indented to line up with the item's text. Each item is written at the depth it holds, so value must be normalized, as every value that cast/1 returns is.

    A numbered item's N is its place in its list. A list ends at any block other than a list item, blank or not, at an item less deep than its own items, and at an item of the other kind at the same depth. Items deeper than the list's own do not end it, and a blank item is not counted.

    Bold and italic are dropped. A link is written as its text followed by its URL in parentheses, or as its text alone when the text is the URL, without mailto: for an email address. A link without text is written as its URL.

    Examples

    iex> RichardBurton.RichText.to_plain_text([
...>   %{"type" => "paragraph", "children" => [%{"text" => "Signed by"}]},
...>   %{"type" => "list-item", "list" => "numbered", "depth" => 0,
...>     "children" => [%{"text" => "Isabel Burton"}]},
...>   %{"type" => "list-item", "list" => "bulleted", "depth" => 1,
...>     "children" => [%{"text" => "on the title page,\nin ink"}]},
...>   %{"type" => "list-item", "list" => "numbered", "depth" => 0,
...>     "children" => [%{"text" => "Richard Burton"}]}
...> ])
"Signed by\n\n1. Isabel Burton\n  - on the title page,\n    in ink\n2. Richard Burton"

iex> RichardBurton.RichText.to_plain_text([
...>   %{"type" => "paragraph", "children" => [
...>     %{"text" => "See "},
...>     %{"type" => "link", "url" => "https://example.com", "children" => [%{"text" => "the catalogue"}]},
...>     %{"text" => " or "},
...>     %{"type" => "link", "url" => "mailto:a@b.com", "children" => [%{"text" => "a@b.com"}]}
...>   ]}
...> ])
