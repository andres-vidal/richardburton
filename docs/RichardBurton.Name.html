    RichardBurton.Name (richard_burton v0.1.0)

    Functions shared by the records that are found by a name, such as RichardBurton.Author, RichardBurton.Publisher and the titles of RichardBurton.OriginalBook.

    A name is searched in two passes. The prefix pass finds the names that start with the term, ignoring case. When it finds none, the fuzzy pass finds the names that share enough trigrams with the term to be a misspelling of it.

    Summary

    Functions

    flatten(names)

    Flattens records or maps with a name to the names they are, as get_name/1 reads each one. A value that is not a list is returned unchanged.

    get_name(value)

    Returns the name of a record with a name field or of a map with a :name or "name" key, and nil for any other map. Any other value, such as a string, is returned unchanged, so a name that is not a string reaches the changeset and is refused there.

    nest(names)

    Nests a flat publication's list of names into the maps a schema with a name field casts. A value that is not a list is returned unchanged, for the changeset to refuse.

    search(schema, term)

    Returns the rows of schema whose name starts with term, or, when none does, the rows whose name resembles it.

    search(schema, term, pass)

    Returns the rows of schema whose name matches term in one pass: :prefix or :fuzzy.

    similar_to(binding, field, term)

    Returns a condition that holds when field of the named binding binding is similar enough to term to be a misspelling of it.

    starts_with(binding, field, term)

    Returns a condition that holds when field of the named binding binding starts with term, ignoring case.

    Functions

    flatten(names)

    Flattens records or maps with a name to the names they are, as get_name/1 reads each one. A value that is not a list is returned unchanged.

    Examples

    iex> RichardBurton.Name.flatten([%{"name" => "Noonday Press"}, %{"name" => "Penguin"}]) ["Noonday Press", "Penguin"]

    iex> RichardBurton.Name.flatten("Noonday Press") "Noonday Press"

    get_name(value)

    nest(names)

    Nests a flat publication's list of names into the maps a schema with a name field casts. A value that is not a list is returned unchanged, for the changeset to refuse.

    Splitting a written-down string into names is done by the CSV codec, before a value reaches here.

    Examples

    iex> RichardBurton.Name.nest(["Machado de Assis", "Clarice Lispector"]) [%{"name" => "Machado de Assis"}, %{"name" => "Clarice Lispector"}]

    iex> RichardBurton.Name.nest("Machado de Assis") "Machado de Assis"
