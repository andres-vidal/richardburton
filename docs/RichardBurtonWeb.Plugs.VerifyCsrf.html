    RichardBurtonWeb.Plugs.VerifyCsrf (richard_burton v0.1.0)

    Checks the CSRF token of a request that can change data, by the double-submit pattern. A GET, HEAD or OPTIONS request passes unchecked.

    Any other request must carry an rb-csrf-token header with a valid RichardBurton.Auth.Csrf token for the subject that Authenticate.Cookie assigned, so that plug must run first. Another site can make a browser send the session cookie, but it cannot read the token to put it in the header. The check adds to the protection of the SameSite=Lax cookie.

    A request that fails the check is refused with a 403 and the reason invalid_csrf.
