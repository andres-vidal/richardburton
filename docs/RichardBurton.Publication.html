    RichardBurton.Publication (richard_burton v0.1.0)

    A publication: one translated edition of an original book, and the write paths that change one.

    Identity is a composite key: the title, the year, the translated book, and the fingerprints of the countries and publishers. The database computes and enforces it (see RichardBurton.Identity), so the same edition cannot be stored twice. The near-duplicates that key cannot catch are Publication.Duplicates.

    Five words carry specific meanings here:

    • tombstone — a soft-deleted row. delete/2 sets deleted_at rather than removing anything, so the row, its sources and its history are kept and restore/3 can bring it back. Every read leaves tombstones out, and the composite-key index is partial, so a tombstone never blocks importing the same publication again.
    • winner and losers — in a merge, the publication that is kept and the publications merged into it. The winner keeps its own fields. The losers add their countries, publishers, sources and notes to it, and are then tombstoned. A merge given notes of its own sets the winner's notes to them instead of adding the losers' (see merge/4).
    • absorbed — the state of a loser after the merge, as Publication.History.absorbed/1 defines it. It is not in the trash, and restore/3 refuses it with {:error, :absorbed}. Undoing the merge brings it back.
    • compensate — to apply the action that undo/3 uses to reverse a recorded entry. The compensating action is recorded as a new entry, which can be undone in turn.

    A publication's notes are rich text about it, as RichardBurton.RichText describes it, or nil when it has none. Blank notes are stored as nil. The notes are not part of the composite key, and the search does not read them.

    A publication's countries, publishers, translators and original authors are sets. The link tables keep no order, and a preload reads each set sorted, by code for countries and by name for the others, as the search index lists them. A history snapshot lists them in that order too, so two snapshots differ only when a set changed.

    Every mutation records an entry in Publication.History inside the same transaction, and signals Publication.Index.Refresher once per operation.

    merge(winner_id, loser_ids, actor \\ History.system_actor(), opts \\ [])

    Merges the publications with the ids loser_ids into the one with the id winner_id, and records the merge with one merged entry by actor on the winner, in one transaction. actor must be a string and opts a keyword list, so a call that passes options passes the actor before them.

    The winner keeps its title, year, translated book and original book. It gains the countries and publishers of the losers, and their sources after its own, leaving out a source it already holds. The losers are then tombstoned, and their distinctions from each other and from the winner are deleted (see Publication.Duplicates.forget/1). The entry names the losers, so undo/3 can undo the whole merge.

    The merged notes are the value of the :notes option when opts holds it, cast and validated as the notes of an update are, so nil or a blank value leaves the winner without notes. Without that option, the merged notes are the winner's notes followed by the blocks of each loser's notes, in the order of loser_ids. A loser's notes are left out when they are nil, blank, or equal to notes already included. When the winner has no notes, the merged notes are the losers'.

    Returns {:ok, winner}, preloaded. Returns {:error, :conflict} when the merged publication would have the composite key of another publication, {:error, :not_found} when one of the publications is missing or deleted, {:error, :self} when loser_ids holds winner_id, {:error, :no_losers} when loser_ids is empty, and {:error, errors} when the merged publication is invalid, such as when the merged notes are too long, or the :notes value is not rich text. Nothing is written when it returns an error.

    preload(data)

    Preloads the countries, publishers, sources and translated book of a publication or a list of them, with the translated book's authors and original book, and the original book's authors.

    restore(id, actor \\ History.system_actor(), changes \\ nil)

    Brings back the deleted publication with the id id, and records a restored history entry by actor, in one transaction. When changes are given, they are applied to the publication first, in the same transaction, and recorded as an update before the restore.

    Returns {:ok, publication}. Returns {:error, :not_found} when there is no such deleted publication, and {:error, :absorbed} when the publication is absorbed, which only undoing the merge brings back.

    When a publication that is not deleted has the same composite key, which happens when the same publication was imported again or a name was corrected to match, the result is {:error, {:conflict, twin}}, where twin is that publication. Nothing is written then, not even the changes. Changes that do not validate return their errors and write nothing either.

    undo(id, version, actor \\ History.system_actor())

    Undoes the entry with the version version in the history of the publication with the id id, by applying the action that compensates it. The compensating action is recorded as a new entry by actor.

    Returns the result of that action. Returns {:error, :not_found} when there is no such entry, and {:error, :conflict} when the entry is not undoable (see Publication.History.undoable?/3).

    An un-merge is undone by merging the same publications again, with the notes that the merge it undid left on the winner.

    update(id, attrs, actor \\ History.system_actor())

    Applies attrs to the publication with the id id that is not deleted, and records the change with an updated history entry by actor, in one transaction. A save that changes nothing records no entry.

    Returns {:ok, publication}, preloaded. Returns {:error, :not_found} when there is no such publication, {:error, errors} when attrs is invalid, and {:error, :conflict} when another publication has the composite key the change would give it.

    with_ids(ids)

    Returns the publications with the ids ids, deleted ones included, preloaded, in the order of ids. Every id must be a stored publication's.

    The countries, publishers, translated book, original book and both lists of authors are read in one query that joins them, sorted the way the associations' preload_order sorts them. The sources are read in a second query, so that many sources do not multiply the rows of the first.
