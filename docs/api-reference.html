richard_burton
v0.1.0

    API Reference richard_burton v#0.1.0

    Modules

    RichardBurton

    The namespace of the platform's contexts: the publications and the books, names and countries they are built from, accounts and invitations, import documents, and mail. Each context is a module under RichardBurton.

    RichardBurton.Application

    Starts the platform's supervision tree, after copying configured values into the environment variables that are unset.

    RichardBurton.Auth

    Verifies identity-provider tokens through the implementation set by the :auth_service application setting, RichardBurton.Auth.Google by default. The setting lets tests use a mock.

    RichardBurton.Auth.Access

    Broadcasts that a person's access may have changed, on a PubSub topic for that person.

    RichardBurton.Auth.Claims

    Validates the claims of an OIDC ID token: issuer, audience, subject, expiry and email. Signature verification is performed separately (see RichardBurton.Auth.Google); this module only checks the decoded claims.

    RichardBurton.Auth.Csrf

    The token of the double-submit CSRF check. Sign-in sets it in a cookie that is not http_only, and RichardBurtonWeb.Plugs.VerifyCsrf requires each state-changing admin request to carry the same token in the rb-csrf-token header.

    RichardBurton.Auth.Google

    Google identity-provider implementation of the RichardBurton.Auth behaviour.

    RichardBurton.Auth.JWKS

    Behaviour for fetching a JSON Web Key Set (JWKS): the signing keys and issuer used to verify ID tokens, plus the cache lifetime the provider advertises.

    RichardBurton.Auth.JWKS.Google

    RichardBurton.Auth.JWKS implementation that fetches from Google: the issuer from Google's OpenID configuration and the signing keys from its OAuth2 certs endpoint (respecting the certs' Cache-Control: max-age).

    RichardBurton.Auth.JWKS.Stub

    RichardBurton.Auth.JWKS implementation that fetches nothing.

    RichardBurton.Auth.KeyStore

    Caches a provider's JWKS signing keys and keeps them fresh so that key rotation does not require restarting the server.

    RichardBurton.Auth.Recaptcha

    Verifies reCAPTCHA tokens through the implementation set by the :auth_recaptcha_service application setting, RichardBurton.Auth.Recaptcha.Google by default. The setting lets tests use a double.

    RichardBurton.Auth.Recaptcha.Google

    The RichardBurton.Auth.Recaptcha implementation that asks Google's verification endpoint, GOOGLE_RECAPTCHA_VERIFICATION_URL, with the secret GOOGLE_RECAPTCHA_SECRET_KEY.

    RichardBurton.Auth.Session

    Server-side (stateful) app sessions. Each session is a row in auth_sessions holding the authenticated user's subject_id and the SHA-256 hash of an opaque token. The raw token is set as the rb-session cookie and looked up on every request, so a session can be revoked instantly by deleting its row.

    RichardBurton.Author

    A name credited on a book: a translator of a translated book, or an author of an original book. Each name is stored once. See RichardBurton.Name.

    RichardBurton.Country

    A country a publication was published in, stored by its ISO 3166-1 alpha-2 code, and the table of every country the platform knows.

    RichardBurton.Document

    An import document: a named batch of rows being prepared for the database, stored so that work on it can continue later.

    RichardBurton.Document.Update

    One Yjs update to a document's content, stored as opaque bytes. Updates are written in the order of their ids.

    RichardBurton.Email

    An email the platform sends: a message from the contact form to the research team, or a message the platform writes itself, such as a confirmation or an invitation.

    RichardBurton.FlatPublication

    A publication in its flat shape: the title, year, countries, publishers, translators (authors), original title, original authors, sources and notes side by side. Each list of countries, publishers, authors or sources holds names, country codes or source texts. The notes are rich text, as RichardBurton.RichText describes it, or nil.

    RichardBurton.Identity

    The composite keys that stop an original book, a translated book or a publication from being stored twice. The database computes and enforces them, and this module is how the application asks it.

    RichardBurton.Invitation

    A role held for an email address until whoever owns it signs in.

    RichardBurton.Mailer

    Sends a RichardBurton.Email through Swoosh.

    RichardBurton.Name

    Functions shared by the records that are found by a name, such as RichardBurton.Author, RichardBurton.Publisher and the titles of RichardBurton.OriginalBook.

    RichardBurton.OriginalBook

    An original book: a title and the authors who wrote it.

    RichardBurton.Publication

    A publication: one translated edition of an original book, and the write paths that change one.

    RichardBurton.Publication.Chart

    Describes a chart of publications, and counts what the chart shows.

    RichardBurton.Publication.Codec

    Converts publications between their flat and nested shapes, and reads and writes them as CSV.

    RichardBurton.Publication.Duplicates

    Finds publications that are likely the same record entered twice.

    RichardBurton.Publication.Duplicates.Distinction

    One remembered "these two are not the same". Stored for the pair, lower id first, so the answer is the same however it is asked.

    RichardBurton.Publication.History

    The append-only log of changes to publications. Each row records one change to one publication: the action, a flat snapshot of the publication after it, the actor, and a version that numbers the publication's entries in order.

    RichardBurton.Publication.Import

    Inserts a batch of new publications in one transaction, with a number of queries that does not depend on the number of rows.

    RichardBurton.Publication.Index

    Full-text search over the publication index.

    RichardBurton.Publication.Index.Excerpt

    Builds the highlighted text that shows why a publication matched a search.

    RichardBurton.Publication.Index.Keywords

    Maps the words someone typed onto the words the index actually contains.

    RichardBurton.Publication.Index.Query

    Builds the query a parsed search term resolves to: the WHERE and ORDER BY expressions that Publication.Index runs for the alternatives Publication.Index.Term.parse/1 returns. Nothing here reads a publication.

    RichardBurton.Publication.Index.Refresher

    Rebuilds the materialized views the index reads: flat_publications, the flat rows the index lists, and search_documents and search_keywords, which are built from them. A write calls refresh/0 once for each operation, such as a bulk insert or an update, after it commits.

    RichardBurton.Publication.Index.SearchDocument

    A publication's search document: the tsvector that a search's free words are matched against, read from the search_documents materialized view. Its id is the id of the publication in flat_publications.

    RichardBurton.Publication.Index.Term

    Parses a search term into the structure Publication.Index builds a query from.

    RichardBurton.Publication.Insights

    Counts the publications in the index, the distinct works and names in them, and a chart of them. describe/2 counts either every publication or the ones a search matches.

    RichardBurton.Publication.Kind

    Tells whether a publication is a first translation of its work, a retranslation or a reissue, and which earlier publications it follows.

    RichardBurton.Publication.Links

    Finds the stored rows that publications link to, and inserts the ones that are missing: their countries, their publishers, and their translated books, with the original books and authors those link to. It works on a list of publications at once, with a number of queries that does not depend on the length of the list.

    RichardBurton.Publisher

    A publisher of publications. Each name is stored once. See RichardBurton.Name.

    RichardBurton.Release

    Database tasks for a release, which runs without Mix.

    RichardBurton.Repo

    The Ecto repository, extended with insert_in_chunks/3, which inserts a list longer than one statement can hold.

    RichardBurton.RichText

    An Ecto type for rich text stored in a jsonb column, and functions that measure rich text and convert it to and from plain text.

    RichardBurton.Source

    A source of a publication: a free-text entry that records where the publication's data was collected, so a reader can check it. A publication's sources are ordered by position, belong to it alone and are deleted with it, and they change with the publication's own update.

    RichardBurton.TranslatedBook

    A translated book: an original book, and the people who translated it.

    RichardBurton.User

    An account: the identity provider's subject id, the email address it was made for, and the role it holds.

    RichardBurton.Util

    Functions on maps and keyword lists that no single context owns.

    RichardBurton.Validation

    Validations shared by several schemas, and get_errors/1, which reduces a changeset's errors to the codes the API returns.

    RichardBurton.Vocabulary

    Lists, checks and renames the names that publications are built from: authors, who are translators or original authors, and publishers.

    RichardBurtonWeb

    The entrypoint for defining your web interface, such as controllers, channels and so on.

    RichardBurtonWeb.Actor

    Names the user who made a request, as the actor of the history entries the request records.

    RichardBurtonWeb.CountryController

    Lists the countries, named in the language of the locale parameter.

    RichardBurtonWeb.DevSessionController

    Signs in without Google, as a development user with the role the request asks for, and sets the cookies of RichardBurtonWeb.SignInCookies.

    RichardBurtonWeb.DocumentChannel

    Relays one import document's changes between the people who have it open, and tracks who they are.

    RichardBurtonWeb.DocumentController

    The import-document endpoints: creating, listing, renaming, archiving and unarchiving documents, and reading, appending and compacting their updates.

    RichardBurtonWeb.DocumentSocket

    The socket for editing import documents live, with one RichardBurtonWeb.DocumentChannel per document.

    RichardBurtonWeb.E2EResetController

    Empties the database between end-to-end tests: it truncates every table but the migration ledger, restarts the identity sequences, and refreshes the search index.

    RichardBurtonWeb.EmailController

    The public contact form. It is the only write that needs no session, so a reCAPTCHA check guards it instead.

    RichardBurtonWeb.Endpoint

    The HTTP entry point: the sockets, and the plugs every request goes through before the router, such as request parsing and CORS.

    RichardBurtonWeb.ErrorJSON

    Renders the errors the endpoint raises, such as an unknown route or a crash, as a JSON body that holds the status text alone, like %{errors: %{detail: "Not Found"}}.

    RichardBurtonWeb.FallbackController

    Turns an error returned by a controller action into a JSON response.

    RichardBurtonWeb.InsightsController

    Returns the counts from RichardBurton.Publication.Insights.describe/2 for every publication in the index, or for the ones the search parameter matches. The search is parsed the same way as an index search.

    RichardBurtonWeb.InvitationController

    Invitations: offering a role to an address, listing what is outstanding, resending, and withdrawing.

    RichardBurtonWeb.NameController

    Lists the names of the records of one schema with a name field, such as RichardBurton.Author or RichardBurton.Publisher. The route names the schema in its :assigns, as schema.

    RichardBurtonWeb.OriginalBookController

    Lists the original books, each with its title and its authors' names.

    RichardBurtonWeb.Params

    Reads whole numbers out of request parameters. A parameter is a string when it comes from the path or the query string, and can be an integer when it comes from a JSON body, so each function takes either.

    RichardBurtonWeb.Plugs.Authenticate.Bearer

    Authenticates a request by the identity-provider token in its Authorization: Bearer header (see RichardBurton.Auth), and assigns the :subject_id and :email the token vouches for.

    RichardBurtonWeb.Plugs.Authenticate.Cookie

    Authenticates a request by the app's own rb-session cookie (see RichardBurton.Auth.Session), and assigns the session's :subject_id.

    RichardBurtonWeb.Plugs.Authorize

    Admits a request when the subject that an Authenticate plug assigned holds the given role, or a role that outranks it.

    RichardBurtonWeb.Plugs.Authorize.Recaptcha

    Admits a request whose recaptcha_token param the reCAPTCHA provider verifies, through RichardBurton.Auth.Recaptcha.

    RichardBurtonWeb.Plugs.IgnoreBlankSearch

    Removes a search parameter that holds nothing but whitespace, so the request is answered as if it had no search.

    RichardBurtonWeb.Plugs.VerifyCsrf

    Checks the CSRF token of a request that can change data, by the double-submit pattern. A GET, HEAD or OPTIONS request passes unchecked.

    RichardBurtonWeb.Presence

    Tracks who has each import document open.

    RichardBurtonWeb.PublicationController

    The publication endpoints: listing, searching and exporting the index, validating publications, the writes (insert, update, merge, delete, restore and undo), the history, and the duplicate review.

    RichardBurtonWeb.Refusal

    Answers a request with an error status and the JSON body %{error: reason}, and halts the connection so that no later plug or action runs.

    RichardBurtonWeb.Router

    The routes, grouped by what each pipeline requires: public reads, writes behind a session and a role, and the development routes, which are not compiled in production.

    RichardBurtonWeb.SessionController

    Signs in with an identity-provider token, and signs out.

    RichardBurtonWeb.SessionCookie

    A read-only Plug.Session.Store that returns the raw value of the rb-session cookie as %{"token" => token}.

    RichardBurtonWeb.SignInCookies

    Sets and deletes the two cookies of a signed-in browser

    RichardBurtonWeb.Telemetry

    Runs a telemetry poller for the app's own periodic measurements, and lists the metrics the LiveDashboard charts: request and query durations, and the memory and run queues of the VM.

    RichardBurtonWeb.UserController

    Reads the signed-in user, lists the users, and changes or removes a user's access.

    RichardBurtonWeb.VocabularyController

    Lists, checks and renames the author and publisher names that publications are built from. See RichardBurton.Vocabulary. A kind that RichardBurton.Vocabulary.kinds/0 does not list is a 404.

    Mix Tasks

    mix rb.invite

    Offers a role to an email address, as RichardBurton.Invitation.invite/2 does, and prints what happened.

    mix rb.load_data

    Inserts the publications in the data.csv file of the current directory, all or none, with RichardBurton.Publication.insert_all/2. When the file cannot be read, or a row is invalid or already stored, the task prints the error and inserts nothing.
