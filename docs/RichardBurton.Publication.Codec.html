    RichardBurton.Publication.Codec (richard_burton v0.1.0)

    Converts publications between their flat and nested shapes, and reads and writes them as CSV.

    The flat shape is the one RichardBurton.FlatPublication has: title, year, countries, publishers, authors, original_title, original_authors, sources and notes, side by side. Each list of countries, publishers, authors or sources holds names, codes or source texts, and the notes are rich text (see RichardBurton.RichText).

    The nested shape is the one RichardBurton.Publication.changeset/2 casts. Its list fields hold child maps, such as %{"name" => name}, and the translators, the original title and the original authors are inside the translated book:

    %{
  "title" => title,
  "year" => year,
  "notes" => blocks,
  "countries" => [%{"code" => code}],
  "publishers" => [%{"name" => name}],
  "sources" => [%{"content" => text, "position" => 0}],
  "translated_book" => %{
    "authors" => [%{"name" => name}],
    "original_book" => %{"title" => title, "authors" => [%{"name" => name}]}
  }
}

    Functions

    flatten(publication)

    Flattens a nested publication into the flat shape, the inverse of nest/1. Takes a Publication struct, a nested map with atom or string keys, a list, or a %{publication:, errors:} pair.

    A map comes back with string keys. Its list fields hold the names or codes of their child maps. The translated book's authors, and its original book's title and authors, come back as authors, original_title and original_authors. Any other field of the translated book or the original book is left out. When translated_book is not a map, such as the error :required, it is kept under its own key. Every other entry keeps its key and value, nested maps included.

    A Publication struct comes back as a FlatPublication struct with the same id. A pair comes back with its publication flattened, and with its errors as flatten_errors/1 returns them.

    Examples

    iex> RichardBurton.Publication.Codec.flatten(%{ ...> "title" => "Dom Casmurro", ...> "translated_book" => %{ ...> "authors" => [%{"name" => "Helen Caldwell"}], ...> "original_book" => %{ ...> "title" => "Dom Casmurro", ...> "authors" => [%{"name" => "Machado de Assis"}] ...> } ...> } ...> }) %{"authors" => ["Helen Caldwell"], "original_authors" => ["Machado de Assis"], "original_title" => "Dom Casmurro", "title" => "Dom Casmurro"}

    iex> RichardBurton.Publication.Codec.flatten(%{ ...> translated_book: %{id: 7, original_book: %{title: "Iracema"}} ...> }) %{"original_title" => "Iracema"}

    flatten_errors(errors)

    Flattens the errors of a nested publication, as RichardBurton.Validation.get_errors/1 returns them, into errors by flat field, the shape RichardBurton.FlatPublication.validate/2 reports. Nil and an atom, such as :conflict, are returned as they are.

    A map comes back with string keys, and with the errors of the translated book's fields under the flat names flatten/1 gives them. The errors of a list of child maps, such as the countries, become one code: the code of the first child that has an error.

    Examples

    iex> RichardBurton.Publication.Codec.flatten_errors(%{
...>   countries: [%{}, %{code: :alpha2}],
...>   translated_book: %{original_book: %{title: :required}}
...> })
%{"countries" => :alpha2, "original_title" => :required}

    from_csv(path)

    Reads a CSV of publications: one row each, columns named by a header.

    The header decides which column is which, so they may be written in any order and a column the file does not carry reads as empty. A name the table does not know is ignored, which is what lets a spreadsheet keep a column of its own.

    A notes cell holds plain text, which may run over several lines inside quotes, and reads as the rich text RichardBurton.RichText.from_plain_text/1 returns for it: a paragraph for each part of the text between blank lines, with a link for each web address or email address in it. A blank or missing notes cell reads as nil.

    nest(flat_publication)

    Nests a flat publication into the nested shape. Takes a FlatPublication struct, a flat map with atom or string keys, or a list of either.

    A map comes back with string keys. Its list fields hold child maps, and its authors, original_title and original_authors are under translated_book. Only the fields the map holds are written: a map without authors gets a translated book without "authors", and a map without any of the three gets no translated book. Every other entry keeps its key and value.

    A FlatPublication comes back as the Publication struct the nested shape casts to.

    Examples

    iex> nested = ...> RichardBurton.Publication.Codec.nest(%{ ...> "title" => "Dom Casmurro", ...> "authors" => ["Helen Caldwell"], ...> "original_title" => "Dom Casmurro", ...> "original_authors" => ["Machado de Assis"] ...> }) iex> nested["translated_book"]["authors"] [%{"name" => "Helen Caldwell"}] iex> nested["translated_book"]["original_book"]["title"] "Dom Casmurro"

    iex> RichardBurton.Publication.Codec.nest(%{original_title: "Iracema"}) %{"translated_book" => %{"original_book" => %{"title" => "Iracema"}}}

    to_csv(flat_publications)

    Writes publications as a CSV with a header, in the shape from_csv/1 reads.

    The columns come in this order: title, year, countries, publishers, authors, original_title, original_authors, sources and notes. The file has a column for each of them that the first publication holds, so every publication must hold the same fields. The notes are written as the plain text RichardBurton.RichText.to_plain_text/1 returns for them.
